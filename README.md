# Personal site

A Next.js personal website starter with sections for games, software, and an about page. Its palette takes inspiration from Techopolis, while its information structure takes inspiration from [orinks.net](https://orinks.net/).

## Run locally

```sh
npm install
npm run dev
```

Open http://localhost:3000.

## Add your content

Edit `content/site.ts` to add projects and update release links. Only repositories with published releases are listed; the Software page currently contains seven stable releases and STAR Manager's prerelease, checked on October 1, 2026. The Access Hub development build is excluded by choice. The Games page stays empty until a game is published. The working brand is **Alex's Loop** for Alex Chapman and the intended domain is `alexoloopios.com`.

## Deploy

The site uses standard Next.js settings and is ready for a Vercel project once its content is ready. No project or domain is linked yet.
